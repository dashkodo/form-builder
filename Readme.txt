База з питаннями в файлі questions.txt
Формат файлу


[назва секціі]
QuestionType=<тип питання, підтримуються Longtext, Text, Radio, Checkbox, Date, Phone, Photo. Moжна додавати required, наприклад Date required>
Текст питання
Поясненн для питання якщо треба, необовязково
    Варіант1
    Варіант2[free]
---
QuestionType=Radio required
Згода на обробку персональних даних
Я підтверджую, що ознайомлений(а) з метою збору та обробки моїх персональних даних і надаю добровільну згоду на їх обробку, зберігання та використання відповідно до вимог Закону України «Про захист персональних даних». Надані мною дані можуть використовуватися виключно з метою проведення опитування, тестування, оцінювання або виконання інших завдань, визначених організатором збору інформації, та не підлягають передачі третім особам без законних підстав.
    Я підтверджую
---
Для текстових питаннь і дати, варіанти відповіді не працюють.
модифікатор [free] для варіанта відповіді додасть необовязкове текстове поле для даного варіанта.

Для фото використовуйте тип:
QuestionType=Photo required filenameFrom="ПІБ" folder=photo

де:
filenameFrom="ПІБ" -> взяти назву файлу зі значення поля з питанням "ПІБ" (тобто з введеного тексту);
folder=photo -> папка для збереження (можна змінювати, за замовчуванням photo).

filenameFrom також підтримує ключ поля (наприклад q1) для сумісності, але рекомендовано використовувати текст питання.

Після збереження в CSV буде записано відносний шлях до фото.

Фото автоматично обрізається до співвідношення сторін 3:4 (портрет), щоб бути ближчим до формату документів.

Результат зберігається у data.csv

Для Docker:
- Використовується змінна FORMS_STORAGE_DIR для каталогу збереження data.csv і фото.
- У Start.bat змонтовано окрему host-директорію storage в /var/www/html/storage і встановлено FORMS_STORAGE_DIR=/var/www/html/storage.
- Це дозволяє зберігати фото з динамічними іменами без попереднього знання назв файлів.

для запуску ->
1) Створити .instatunnel.env файл
2) Створити questions.txt
3) Запустити Start.bat

Візуальний редактор:
- Відкрити /admin.php
- Вкладка "Питання" дозволяє редагувати sections/questions і зберігати в questions.txt
- Вкладка "Дані" показує збережені рядки з data.csv і прев'ю фото зі storage
